# 계산 방법

같은 seed의 작업조건을 유지한 채 8개 공유조합의 계획을 구하고, 각 계획을 같은 실제 합성 상태로 평가한다. 계획 단계에는 허용된 관측 정보만 전달한다. 미공유 참여자의 상세정보는 고정 공개 기본값으로 대체한다.

## 공유가치와 기여도

KPI는 작을수록 좋다. 조합 S의 공유가치는 미공유 KPI에서 해당 조합의 KPI를 뺀 값이다. 한 참여자의 정보가 추가될 때 결과가 얼마나 좋아지는지를 가능한 모든 참여 순서에서 계산하고, 그 평균을 해당 참여자의 기여도로 사용한다.

세 참여집단 N에 대해 다음 식을 사용한다.

```text
V(S) = J(NONE) - J(S)
φ_i = Σ[S ⊆ N\{i}] (|S|! (3-|S|-1)! / 3!) × (V(S∪{i}) - V(S))
```

seed별 기여도의 합은 전체공유 가치와 같다. 음수 기여도도 과학적 계산값에 그대로 남긴다. 100개 seed의 평균 기여도를 구한 뒤 점수 정책을 한 번 적용한다.

## 가상점수

유효한 정식 실행과 양수 전체공유 가치가 확인되면 평균 기여도의 양수 부분을 사용한다. 그 비율로 1,000점을 배분하고, 각 몫의 정수 부분을 먼저 준 뒤 소수 나머지가 큰 순서로 잔여 점수를 배분한다. 동률이면 참여자 식별자의 사전순을 사용한다. smoke 또는 불완전 실행에서는 점수 정책이 활성화되지 않는다.

## 통계와 재현

두 모델은 seed 0~99를 사용하며 조합 간 같은 seed를 짝지어 비교한다. 기술통계는 평균·중앙값·최솟값·최댓값과 표본 표준편차(n−1)를 포함한다. 신뢰구간은 고정 난수 seed로 10,000회 paired bootstrap을 수행하고 2.5·97.5 백분위수를 선형 보간한다. 배차 bootstrap seed는 20260910, CY는 20260928이다.

`scientific.json`은 모델별 기존 정규화를 적용한 결과다. 배차는 측정 실행시간을 제외한다. CY는 실행시간과 지정된 시각 필드를 제외하고 조합·seed 순서를 고정한다. public 도구는 이 파일의 원본 바이트 SHA-256을 [reference manifest](../results/reference-manifest.json)와 비교한다. 실행 기록과 import 경로는 별도 receipt에 보존한다.

도구는 고정 source/config/reference manifest를 확인한 뒤 실행 API를 호출한다. 기존 formal CLI와 공개 재현 도구는 별도 진입점이다. CY formal CLI는 `main`, 예상 full commit, clean 상태와 고정 설정을 확인한다. source ZIP은 Git guard가 없는 공개 재현 도구로 실행한다.
